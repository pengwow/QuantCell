# QuantCell AI原生重构计划

## 目标
将QuantCell从传统量化交易软件重构为AI原生量化交易软件，底层使用axon_quant作为引擎，保留QuantCell的前端交互和业务管理能力。

## 核心设计决策

| 决策 | 选择 |
|------|------|
| 重构方式 | 全面重构（集成AI能力+迁移业务逻辑） |
| 前端交互 | 混合模式（传统UI 70% + AI对话 30%） |
| Agent架构 | 分层架构（QuantCell交互层→axon_quant决策层） |
| RL训练 | 完整集成（训练/HPO/分布式/Walk-Forward/模型注册） |

---

## 整体架构 — 5层

```
L5 前端: Vue3 + Ant Design X（传统UI + AI对话面板）
L4 API网关: FastAPI /api/v2/（认证、限流、路由）
L3 业务服务: StrategyService / BacktestService / WorkerService / RLService / ModelRegistryService
L2 AI Agent: InteractionAgent（QuantCell）→ DecisionAgent（axon_quant ReAct）
L1 集成层: axon_quant_sdk/（16个axon_quant子模块封装）
```

---

## Phase 1: axon_quant SDK封装层（Week 1-2）

**目标:** 创建 `backend/axon_quant_sdk/` 包，封装axon_quant 16个Python子模块

### 新建文件

| 文件 | 功能 |
|------|------|
| `backend/axon_quant_sdk/__init__.py` | 版本检查、可用性标志 |
| `backend/axon_quant_sdk/_compat.py` | Python版本检查、导入防护 |
| `backend/axon_quant_sdk/types.py` | 核心类型重导出（Bar, Order, Position等） |
| `backend/axon_quant_sdk/backtest.py` | BacktestEngine封装 |
| `backend/axon_quant_sdk/rl.py` | TradingEnv + PPO/SAC/DQN封装 |
| `backend/axon_quant_sdk/hpo.py` | Optuna HPO封装 |
| `backend/axon_quant_sdk/walk_forward.py` | Walk-Forward验证封装 |
| `backend/axon_quant_sdk/distributed.py` | Ray分布式训练封装 |
| `backend/axon_quant_sdk/registry.py` | ModelRegistry封装 |
| `backend/axon_quant_sdk/tracker.py` | ExperimentTracker封装 |
| `backend/axon_quant_sdk/llm.py` | ReActAgent + SwarmOrchestrator封装 |
| `backend/axon_quant_sdk/trading.py` | PlaceOrderTool/QueryPortfolioTool封装 |
| `backend/axon_quant_sdk/risk.py` | RiskEngine封装（12ns预交易检查） |
| `backend/axon_quant_sdk/oms.py` | OrderManager封装 |
| `backend/axon_quant_sdk/exchange.py` | ExchangeAdapter封装 |
| `backend/axon_quant_sdk/inference.py` | ONNX/Candle推理引擎封装 |
| `backend/axon_quant_sdk/explain.py` | SHAP/反事实解释封装 |
| `backend/axon_quant_sdk/ensemble.py` | EnsembleManager封装 |
| `backend/axon_quant_sdk/compliance.py` | 合规审计封装 |

### 设计原则

- 每个模块用 `try/except ImportError` 包裹，暴露 `AVAILABLE` 标志
- 重导出axon_quant类型，与现有 `axond/types.py` 并存
- QuantCell的SQLAlchemy配置 → axon_quant的dict/struct配置桥接
- axon_quant Rust异常 → Python领域异常转换

### 关键参考文件
- `backend/worker/axon_worker_system.py` — 现有axon集成参考
- `backend/axond/` — 现有axon守护进程目录
- `pyproject.toml` — 已有 `axon-quant>=0.1.3` 依赖

### 验收标准
`from axon_quant_sdk.backtest import BacktestService` 可用，且优雅降级（axon_quant未安装时不崩溃）

**目标:** 回测系统集成axon_quant高性能引擎 + Walk-Forward + HPO

### 修改/新建文件

|------|------|
| `backend/backtest/engines/axon_engine.py` | **新增** — axon_quant BacktestEngine适配器 |
| `backend/backtest/walk_forward.py` | **新增** — Walk-Forward验证（axon_quant.walk_forward） |
| `backend/backtest/hpo_runner.py` | **新增** — HPO超参数优化（axon_quant.hpo + Optuna） |
| `backend/backtest/result_analyzer.py` | **新增** — 增强分析（axon_quant.explain SHAP） |
| `backend/backtest/engine_service.py` | **重构** — 委托给axon_quant_sdk.backtest |

- `POST /api/v2/rl/train` — 启动RL训练
- `POST /api/v2/rl/hpo` — 超参数优化

- `GET /api/v2/rl/models` — 列出RL模型
- `POST /api/v2/rl/models/compare` — 比较模型
- `POST /api/v2/rl/deploy/{model_id}` — 部署模型

### 验收标准

| `frontend/src/pages/agent/AgentPanel.tsx` | **新增** — 全局AI面板（Cmd+K） |

### Agent分工
- **InteractionAgent**: NLU意图解析、工具编排、响应格式化、记忆管理
- **DecisionAgent**: ReAct交易循环（Thought→Action→Observation）、RL推理、风控管理、集成投票

### 意图路由
```
用户消息 → InteractionAgent → 意图分类:
  - trading_decision → DecisionAgent（axon_quant ReAct循环）
  - backtest → BacktestService
  - rl_training → RLService
  - strategy_generation → AI策略生成
  - general → 通用对话
```

### 验收标准
用户可通过AI对话完成策略生成→回测→部署的完整流程
