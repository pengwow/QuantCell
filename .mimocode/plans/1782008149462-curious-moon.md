# QuantCell 迁移方案：nautilus_trader → axon_quant

## 概述

将 QuantCell 的底层量化交易框架从 nautilus_trader 迁移到 axon_quant（Rust 内核）。axon_quant 0.1.3 已发布到 PyPI，**仅支持 Python 3.14**。

## 环境要求

| 项目 | 当前 | 目标 |
|------|------|------|
| Python | 3.12/3.13 | **3.14**（axon-quant 0.1.3 要求） |
| axon-quant | 未安装 | `pip install axon-quant==0.1.3` |
| numpy | 2.4.6 | 2.4.6（兼容） |
| pandas | 2.x/3.x | 3.x（兼容） |
| pyarrow | 已有 | 已有（兼容） |

### Python 3.14 安装

```bash
# 使用 pyenv 安装 Python 3.14
pyenv install 3.14.6
pyenv local 3.14.6

# 或使用系统 Python 3.14
# 安装 axon-quant
pip install axon-quant==0.1.3
```

## 迁移架构

### 核心设计原则

1. **不保留 nautilus 接口** — 全面使用 axon_quant 原生 API
2. **保留 strategy/core/ 自研框架** — 无 nautilus 依赖的部分不变
3. **渐进式迁移** — 完成一个子计划后再进入下一个
4. **Python 3.14 必需** — axon-quant 0.1.3 硬性要求

### axon_quant 模块映射

| QuantCell 功能 | nautilus_trader | axon_quant 模块 |
|---|---|---|
| 回测引擎 | `nautilus_trader.backtest.engine` | `axon_quant.backtest.BacktestEngine` |
| 交易所适配器 | `nautilus_trader.adapters.binance/okx` | `axon_quant.exchange.BinanceAdapter/OkxAdapter` |
| 风控引擎 | 配置化 | `axon_quant.risk.DefaultRiskEngine` |
| 订单管理 | `OrderFactory` | `axon_quant.oms.OrderManager` |
| RL 训练 | ❌ | `axon_quant.rl.TradingEnv` |
| 超参优化 | ❌ | `axon_quant.hpo` |
