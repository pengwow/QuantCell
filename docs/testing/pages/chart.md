# 行情图表（/chart）

## 前置
- 环境与 token 注入见 `../README.md` 第一节；本页在 `AuthGuard` 内，必须先注入 token
- 组件：`frontend/src/pages/chart/ChartPage.tsx` + 共享图表壳 `frontend/src/components/chart/ChartShell.tsx`（K 线渲染依赖 klinecharts）
- 数据依赖：`GET /api/v1/data/klines`（默认品种 `BTCUSDT`、周期 `1h`、limit 500）。**K 线为空不影响 L1**——L1 只断言页面骨架与图表容器渲染
- 实时行情（引擎启动 + 交易所连接）是外部依赖，标"按需"；L1 不断言数据推进
- 图表偏好（品种/周期/指标参数/盘口面板）存后端 `config` 的 `uiPrefs`，沿用旧数据目录时页面会恢复到上次品种，属正常

## 验证项

| # | 操作 | 预期（可观测信号） | 层级 |
|---|---|---|---|
| C1 | 注入 token 后打开 `/chart` | 页面渲染图表骨架：品种名可见（全新数据目录为 `BTC/USDT`，沿用旧目录则为上次保存的品种）；周期条出现 `1m` `5m` `15m` `30m` `1H` `4H` `1D` `1W` `2H` `1M` `1Y`；工具栏文本 `指标` `信号提醒` `时区` `设置` `截图` `全屏` 可见；URL 保持 `/chart` | L1 |
| C2 | 页面加载完成后查 network | `GET /api/v1/data/klines` 返回 200（查询参数含 `symbol`、`interval`、`limit=500`）；`GET /api/v1/realtime/config` 已发出（返回 200 或失败，失败只落控制台，不阻塞渲染） | L1 |
| C3 | 观察图表绘图区 | 图表区域内渲染出绘图元素（canvas/SVG 节点）；有数据时可见价格与时间刻度，无数据允许空白；页面**无**`加载K线数据失败`错误提示。K 线为空导致的空白不算失败，如实记录"无数据" | L1 |
| C4 | 点周期条 `1D` | 选中态切到 `1D` 并重发 `GET /api/v1/data/klines`（`interval=1d`）；图表不残留上一周期形态（回归哨：切换竞态） | L2 |
| C5 | 点顶部品种名（如 `BTC/USDT`） | 弹出品种搜索弹窗：标题`搜索品种`、输入框占位`输入品种代码或名称`；`GET /api/v1/data/products` 返回 200，有结果则列出品种条目，无结果显示`未找到匹配的商品` | L2 |
| C6 | 点工具栏 `设置` | 弹出`图表设置`弹窗：含`恢复默认`按钮与`蜡烛图类型`等设置项，可关闭且不报错 | L2 |
| C7 | 点工具 `截图` | 弹出截图预览弹窗并展示当前图表截图；关闭后页面正常 | L2 |
| C8 | 点实时开关（播放/暂停图标按钮，无文本） | 触发 `GET /api/v1/realtime/status`；引擎未运行则依次 `POST /api/v1/realtime/start`、`POST /api/v1/realtime/connect`；按钮进入运行态。K 线随推送更新需交易所连通 —— 失败（无代理/无网络）不算页面缺陷，如实记录 | 按需（交易所实时探测） |
| C9 | 在设置里打开订单簿面板 | 右栏出现订单簿/成交流水；依赖 `depth`/`trades` 推送，未连通时面板为空态 —— 属外部依赖，不判失败 | 按需（交易所实时探测） |

## 历史雷区
- **实时订阅必须先等引擎就绪**：`RealtimeToggleButton` 完成启动/连接后才置 `realtimeActive`，页面才订阅引擎频道。若测试在按钮点完后立刻断言盘口/成交，会看到"订阅失败"（仅控制台）。按需项要等状态回调，不是点击即可
- **WS 重连不恢复动态 topic**：`depth`/`trades` 等动态订阅靠 `wsConnected` 变化触发重订阅，重连瞬间旧订阅已丢失；断线期间订单簿/成交流水恒空态。看到"图表正常但右栏空"先查 WS 连接态
- **200 + 空数组 ≠ 加载失败**：`loadKlineData` 只在抛错时提示`加载K线数据失败`，接口返回空数组时图表静默空白。L1 判空白必须区分"请求失败"与"无种子数据"
- **品种/周期切换竞态**（已修）：并发拉取时旧响应会盖新图，现用请求序号丢弃旧响应并在切换前清空数据引用。若 C4 后仍显示切换前的形态，属该回归复发
- **偏好恢复会改默认品种**：挂载时读后端 `uiPrefs`，旧数据目录可能直接把品种恢复到上次的选择，C1 的 `BTC/USDT` 断言只在全新数据目录成立
- **自动连接失败是静默的**：`realtime_enabled=true` 时页面挂载 1s 后自动启动引擎并连交易所，失败只 `console.error`。打包链路无系统代理，交易所不通很常见，页面骨架仍应完好
