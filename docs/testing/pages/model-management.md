# 模型管理（/model-management）

## 前置
- 环境与 token 注入见 `../README.md` 第一节
- **本页不调用任何后端 API**：表格数据是写死在组件内的 3 条演示数据（LSTM价格预测 / 随机森林分类 / XGBoost回归），新建/删除只改内存，刷新即回到初始三条
- 本页**不在侧边导航里**（菜单只有「模型中心」），只能直接输入 URL 打开
- 详情弹窗的雷达图来自 echarts 独立 chunk，首次打开可能有一瞬空白

## 历史雷区
- **整页是演示壳**：无 API、无 store、无持久化。新建/删除只改 `useState`，刷新或切走再回来数据回到硬编码 3 条 —— 验证**不得**断言"后端已删除/已创建"
- **死按钮**：「训练」「编辑」没有绑定 `onClick`，点了毫无反应（既无请求也无 toast）。若后续接上训练/编辑，G7 与「历史雷区」需同步改
- **入口缺失**：`ConsoleLayout` 菜单里没有 `/model-management` 项，从界面点不到，只能手输 URL。看到"页面进不去"先确认不是导航缺失的误判
- **详情弹窗状态标签是英文原值**：弹窗内「状态」直接渲染 `trained` / `training`（现为 chip 样式但仍是英文原值），而列表状态列是中文「已训练 / 训练中」。断言文案时区分这两处，别把英文当乱码
- **echarts 懒加载**：图表在独立 chunk（`chart-vendor`），详情弹窗首次打开可能空白 1-2 秒；条件轮询等 canvas 出现，别按固定时长判失败
- **删除无确认 + 刷新可恢复**：删除直接删内存行（不同于模型中心页有 confirm Modal），自动化连点容易误删演示行，刷新即复原，不算污染环境
