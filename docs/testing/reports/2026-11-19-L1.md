1. **自动化连发请求 = 假阴性陷阱**：验证中连发 3 次请求互相 abort，abort 气泡被 `bubbleItems` 的 `status!=='abort'` 过滤，呈现为"错误完全静默"，差点误判为前端缺陷。干净单发后 E4b 即过。→ 已写入 `pages/strategy-editor.md` 雷区栏与 `README.md` 技巧栏
2. **图标按钮定位**：AI 入口是纯图标按钮（`aria-label`），文本扫描定位不到 → 已写入技巧栏
3. 教训记录：process 中曾依据 minified 代码特征（`depth>2` vs `||e.detail`）误判 dist 未含修复——minifier 会重命名局部变量/改写表达式，**判断产物新旧必须用"源码状态 + 构建时间线 + 行为测试"三重验证，不做单字符串特征推断**
