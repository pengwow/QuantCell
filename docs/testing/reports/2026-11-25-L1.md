## 过程发现（已回流）

1. **打包缺文件：strategy/templates/*.py 未随 PyInstaller 包走（本轮主修复）**
   - 现象：打包 sidecar 下策略编辑器模板列表 500，sidecar.log 报 `No such file or directory: .../_internal/strategy/templates/cross_sectional.py`
   - 根因：`ai/strategy/routes_strategy.py::_scan_template_list` 按模块 `spec.origin` **读模板 .py 源码**提取参数表单；PyInstaller 只把模块字节码编译进 PYZ，源文件不在包里。开发态（源码树直接跑）永远复现不了
   - 修复：`build-backend.sh` / `quantcell-backend.spec` 补 `--add-data "strategy/templates:strategy/templates"`
   - 闸门（回答"如何打包时/CI 就报错"）：新增 `desktop/scripts/verify-sidecar.sh`，打包末尾冷启动产物、真打「运行时读包内文件」的端点，任一非 2xx 构建即失败；`build-backend.sh` 末尾已接入，CI `desktop-build.yml` 调 build-backend.sh 故同样生效
   - 维护规则已写入 `docs/testing/README.md`：新增读包内文件的端点时给 CHECKS 清单补一行
2. **L1 爬页脚本的模板断言要进下拉取证**：模板列表在「创建策略」弹窗的 antd Select 内（虚拟滚动），`body.innerText` 扫不到；用 `.ant-select-item-option` 文本断言
